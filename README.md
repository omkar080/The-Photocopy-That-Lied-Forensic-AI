# The-Photocopy-That-Lied-Forensic-AI
Domain: AIML
The project includes four AI-based modules: Photocopy Detection, Lie Detection, Forensic AI, and Farm Insurance. To run the project, install the required dependencies, open the project folder in VS Code, and execute the main application file. Users can upload the required input through the interface, and the system processes it using the respective AI module and displays the result. The commands and detailed execution steps are provided in the project guide PDF.
